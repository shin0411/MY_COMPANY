## 1. サブニッチ・ポジショニング3案

飽和カテゴリ「家事・収納・キッチン時短雑貨」を**生活シーンで切る**3案。いずれも「ごく普通の自宅キッチン・居室」「手元＋声のみ・性別不問」で成立する。

### 案A: 朝シーン特化「あさの10分先回り」

| 項目 | 内容 |
|---|---|
| コンセプト一行 | 朝のバタバタを「前日の収納と段取り」で先回りして消す |
| アカウント名候補 | 「あさじたく」「あさラクけんきゅうじょ」「けさのだんどり」 |
| 差別化理由 | 便利グッズ羅列系が多い中、「朝の動線」という時間軸で編集。弁当・朝食準備層の切実な需要に刺さる |
| 想定リスク | 朝ルーティン・弁当系は強豪が多い。ペルソナの視聴時間帯（昼・夜）と「今すぐ実行」が直結しない。朝の自然光撮影に縛られやすい |

### 案B: 夜シーン特化「ねるまえリセット」

| 項目 | 内容 |
|---|---|
| コンセプト一行 | 寝る前10分のキッチンリセットで、明日の自分をラクにする |
| アカウント名候補 | 「ねるまえ10ぷん」「よるリセ」「おやすみキッチン」 |
| 差別化理由 | ナイトルーティン系は「映え」偏重が多い中、生活感のある現実リセットで共感を取る。視聴時間帯21〜23時と完全一致し「見た直後に実行」できる |
| 想定リスク | ルーティンが主役でモノが脇役になりやすく、Stage 2の物販転換がやや遠回り。毎回似た絵になりマンネリ・ネタ枯れしやすい |

### 案C: 空間シーン特化「せまいキッチン攻略」

| 項目 | 内容 |
|---|---|
| コンセプト一行 | せまい・収納が少ない・賃貸でも回るキッチンを、100均中心でつくる |
| アカウント名候補 | 「せまキチ」「せまキチらぼ」「ちいさな台所のミカタ」 |
| 差別化理由 | 収納系の上位アカウントは「広い戸建ての美しいキッチン」が多く、視聴者は真似できない。「うちと同じ条件だ」という当事者性で切る。「せまいキッチン 収納」は検索軸が立っており、TikTok検索流入も取れる。収納グッズが主役なのでStage 2（国内仕入れ物販）と最短で接続する |
| 想定リスク | (1)「せまい」縛りでネタ範囲が限定 → 冷蔵庫・洗面所・玄関など「せまい家全般」へ拡張できる名前にしておく。(2) 広い部屋が映り込むと世界観が崩れる → 手元アップ中心の撮影でそもそも引きを使わない |

### 推奨: 案C「せまいキッチン攻略」

理由は4点。

1. **差別化が構造的**: 競合は「広いキッチンの理想」を売るが、本案は「視聴者と同じ制約下の現実解」を売る。機能比較ではなくポジショニングで勝つ。
2. **保存率が最も高いジャンル**: 収納手順コンテンツは「あとで真似する」ために保存される。保存はTikTokアルゴリズムの最重要シグナルの一つ。
3. **Stage 2への直結**: 収納グッズはTikTok Shopホーム雑貨の主力。アフィリエイト→国内仕入れ物販への移行で商材の一貫性が保てる。
4. **撮影要件と完全一致**: 手元アップ中心のため、キッチンの実寸はほぼ映らない。「せまい」は絵で証明する必要がなく、ごく普通の自宅キッチンで成立する。むしろ生活感が信頼材料になる。

案Bの強み（視聴時間帯との一致）は「平日21時台投稿」として運用面に吸収する（→ §5）。

**性別不問の担保**: ナレーションは一人称を極力使わず「うち」「わが家」で統一（台本10本はこの設計で記述済み）。キャラ設定は「正直な暮らし研究員」で、声の高低・性別を問わず成立。男性声でも女性声でも台本の変更は不要。

## 2. アカウント設計（案C前提）

### メッセージングコア（誰に・何を・なぜ）

- **誰に**: 28〜40歳、せまい・収納が少ないキッチンで毎日料理する人（賃貸・マンション中心、コスパ重視）
- **何を**: 100均中心・大ごとにしない収納と段取りで、「探す・どかす・拭く」を毎日数分ずつ減らす方法
- **なぜ（選ばれる理由）**: 広い素敵キッチンの真似は再現できない。同じ条件での現実解だから「明日うちでできる」

### 表示名・ID

- 表示名: **せまキチ｜せまいキッチンの味方**（検索キーワードを名前に含める）
- ID候補: `@semakichi` / `@semakichi_lab`

### プロフィール文（80字制限内・62字）

> せまいキッチンの味方｜100均・ニトリ・無印で家事ラク｜むずかしいことはしません｜週5本・よる9時ごろ更新｜あとで試す→保存

ポイント: 「誰の味方か」「何で解決するか」「更新頻度の約束」「保存のCTA」を1行ずつ。残り18字は1,000人到達後の書き換え余地（アフィリエイト開始の告知等）に温存。

### アイコン・固定投稿

- **アイコン**: 顔出しなしのため文字ロゴ。テラコッタ（オレンジ系）単色背景に白抜きで「せまキチ」。小さい表示でも判読できる太字。Canva無料版で作成可。
- **固定投稿（3枠）の方針**: 開設2週間は固定なし（データがないため）→ 2週間後に「①保存数1位の動画 ②総集編（10本目） ③シリーズ初回（1本目）」を固定。以後は月1回、保存数上位に入れ替え。

### 世界観・トンマナ

| 要素 | 指定 |
|---|---|
| 色味 | 背景は自宅のまま（生活感OK、隠さない・盛らない）。映像は昼光で明るく統一 |
| テロップ | 白文字＋黒縁取り（または黒文字＋白座布団）。強調色はオレンジ1色のみ。短文・体言止め・ひらがな多め・数字を立てる（「3秒で」「110円で」）。配置は画面中央〜やや上（TikTok/IG両方のUIに隠れないセーフゾーン） |
| 話し方キャラ | 「正直な暮らし研究員」。盛らない・失敗も言う・断定しない・最大級表現（絶対/最強/No.1）を使わない（景表法対応とキャラ設計を兼ねる）。語尾サンプル: 「〜でした」「〜が正直なところ」「うちはこれで十分でした」「〜してみて」 |
| 音 | ナレーションが主役。BGMは音量20%以下のアップテンポ無料曲 |

### Instagramリール転用時の調整点

1. **TikTokロゴ透かし入り動画を転載しない**（リーチ抑制対象）。CapCutから直接書き出した素材を別途アップ。
2. **カバー画像を設定**（IGはグリッド表示があるため。完成カット＋タイトル文字でCanva量産）。
3. **キャプションは長文化**: 手順を箇条書きで書き添えて保存価値を上げる（IGは読まれる）。
4. **ハッシュタグをIG向けに差し替え**: #キッチン収納 #賃貸インテリア #暮らしを整える #100均収納 #時短家事 など。
5. **音源**: ナレーションは自分の声なので権利問題なし。BGMはCapCut内の商用可素材を選んでおけば両プラットフォーム共通で使える。
6. **投稿タイミング**: TikTokの翌日同時刻でよい（運用負荷最小化を優先。1本あたり追加10分以内）。

- ナレーションは話速 約5〜7字/秒で設計済み。そのまま読めば尺に収まる。

## 5. ハッシュタグ・投稿運用戦略

### 基本ハッシュタグセット（1投稿5〜7個）

| 階層 | タグ | 用途 |
|---|---|---|
| 大（広域・毎回1個） | #便利グッズ / #収納 / #時短 のいずれか | レコメンド面の足がかり |
| 中（カテゴリ・毎回2〜3個） | #キッチン収納 #100均収納 #家事ラク #賃貸暮らし | メイン戦場。ペルソナの回遊圏 |
| 小（テーマ・毎回1〜2個） | #シンク下収納 #冷凍庫収納 #引き出し収納 #水切りカゴ など動画の中身に即したもの | 検索流入・関連動画面 |
| 独自（毎回1個） | #せまキチ | シリーズ回遊・ブランド資産化 |

**タグより効くもの**: TikTok検索対策として、(1) キャプション1文目に「せまいキッチン」「シンク下」等の検索語を自然な文で入れる、(2) 動画内テロップにもキーワードを含める（検索はテロップも拾う）。タグの数を増やすより、この2点を毎回守る方が効果的。

### 投稿時刻の使い分け

- **平日（月・水・金）21:15**: 本命枠。ペルソナの就寝前スマホ時間＋オーナーが初動対応できる時刻。
- **土曜 11:30**: 昼帯実験枠。家事の合間視聴を取りに行く。
- **4週間後**: アナリティクスの「フォロワーのアクティブ時間」を見て配分を再調整。昼帯が強ければ土日昼を2枠に。
- 連続投稿はしない（最低6時間空ける）。投稿が遅れても欠番にせず翌日に回す（週内本数の維持が優先）。

### 初動1時間プロトコル（アルゴリズム対応）

1. 投稿直後、**自分で固定コメントを打つ**: 品名・売場・サイズ・代替品（例: 「ファイルボックスはダイソーの自立タイプ。セリアの白でもOK。幅10cmが目安」）。コメント欄自体の保存価値を上げる。
2. 投稿後60分は通知ONで**全コメントに返信**。返信は可能なら質問で返して会話を1往復伸ばす。
3. 以降は翌朝・翌夜の2回巡回。質問への回答は固定コメントに追記昇格。
4. 否定的コメントには反論しない。「たしかにそういう場合もありますね。うちの場合は〜でした」で正直キャラを維持。誹謗中傷は返信せず非表示。
5. 「どこで買えますか」には**店名のみ**答える。外部URL・LINE・DM誘導は一切しない（TikTok規約: プラットフォーム外取引誘導の禁止）。

### ステマ規制・#PR表記の切り替えタイミング（重要）

| フェーズ | 状態 | 表記 |
|---|---|---|
| 今回の10本〜1,000人到達まで | 全品自腹購入・リンクなし・報酬なし | **#PR不要**(広告に該当しない） |
| フォロワー1,000人到達 → TikTok Shopアフィリエイト登録・商品リンクを付けた投稿 | 成果報酬が発生 | **その1本目からキャプション冒頭に #PR**＋動画内テロップにも「PR」を表示 |
| 過去動画にあとからアフィリエイトリンクを付ける場合 | 遡って広告化する | **その動画のキャプションも #PR に修正してからリンク付与** |
| メーカー等から商品提供（ギフティング）を受けた場合 | 金銭がなくても提供時点で対象 | その投稿から #PR |

## 6. 週8時間の運用ルーティン

### パイプライン原則: 「1週間先行制作」

土曜に撮る5本は**翌週**に投稿する。常に1週間分のストックがある状態を維持し、平日が崩れても投稿が止まらないようにする。開始前に「準備週末」を1回設け、第1週分5本を撮影・うち2本を編集してからスタートする。

### 週間時間割（合計 約8.25時間）

| 曜日 | 時間 | 作業 | 所要 |
|---|---|---|---|
| 月 | 21:00–22:00 | 21:15投稿 → 固定コメント → 初動返信／土日分をIGリールに転載 | 60分 |
| 火 | 21:30–22:15 | 編集(1)（来週月・水分のカット編集） | 45分 |
| 水 | 21:00–22:00 | 21:15投稿 → 初動返信／前日分をIG転載 | 60分 |
| 木 | 21:30–22:15 | 編集(2)（テロップ・効果音仕上げ） | 45分 |
| 金 | 21:00–22:00 | 21:15投稿 → 初動返信／**来週の台本5本をAI生成→自分の言葉に直す**／明日の買い物リスト確認 | 60分 |
| 土 | 9:30–12:30 | **まとめ撮り5本**（途中11:30に当週分を投稿＋昼休憩中に初動返信） | 180分 |
| 日 | 20:30–22:00 | 編集(3)（残り分）＋ナレーションまとめ録り／21:15投稿 → 初動返信 | 90分 |

- 編集配分は5本÷3枠＝1本あたり約33分が目標。**最初の2週は1本60分かかる前提**で週10時間上限まで使ってよい。3週目以降、テンプレ化で短縮。
- 間に合わない週は**週5本→4本に減らす**（市場知見の週3〜5本レンジ内）。本数より「毎週続いていること」が優先。
- 週次レビュー（金曜の台本作成前に10分）: §7の4指標を確認してから台本に反映。

### まとめ撮りの段取り（1セッションで5本）

1. **Beforeを最初に全部撮る**: 片づけてしまうと撮り直せない。撮影順は「全Before→施工→全After」。これが最重要。
2. **動線一筆書き**: シンク下→シンク上→コンロ→冷蔵庫→引き出しの順に移動し、セット転換を最小化。
3. **1本＝6カット定型**: Before／全部出し／手順×2〜3／完成／取り出しデモ。迷ったらこの型で撮る。
4. **カメラ固定**: 箱＋輪ゴムか100均三脚で俯瞰固定。露出・倍率を固定して5本の色味をそろえる。昼光（午前中）で統一。
5. **撮影中は無言でOK**: 音声は使わない（ナレは日曜夜にCapCutのアフレコでまとめ録り。クローゼット内など布の多い場所で録ると反響が減る）。家族が在宅でも撮影可能。
6. **小道具は金曜までに調達**: 来週分の100均購入を金曜のリストで確定し、土曜朝イチか前日に購入。
7. **CapCutテンプレ化**: 1本目で「テロップスタイル保存」「効果音お気に入り登録」「終了画面（保存してね＋アカウント名）」を作り、2本目以降に複製して使い回す。

## 7. KPI（最初の2週間〜1ヶ月）と改善プロトコル

### 先行指標と遅行指標

- **先行指標（毎週見る・行動を変える対象）**: 3秒残存率、平均視聴維持率、保存率（保存数÷再生数）、コメント数、プロフィールアクセス

| プロフィールアクセス | 再生数の1〜2% | 1.5〜2.5% | フォロー転換の入口 |

### 「伸びない場合」の1ヶ月後チェックポイント（症状別診断）

| 症状 | 見る指標 | 改善アクション |
