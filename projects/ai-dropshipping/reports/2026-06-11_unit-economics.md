# 個人副業AIドロップシッピング 月10万円利益達成のビジネスモデル設計とユニットエコノミクス試算

**作成日**: 2026-06-11
**作成者**: business-development（事業企画）
**前提**: 個人副業 / 週5-10時間 / 0円スタート / TikTok Shop・Instagramショッピング

---

## エグゼクティブサマリー

結論を先に述べる。**月10万円利益はギャンブル寄りの「現実的だが達成確率20-30%」**である。理由は以下。

- オーガニック集客の構造上、収益化までに6-9ヶ月の助走期間が必要
- 週5-10時間の稼働では、月100本以上の投稿が必要なシナリオAは破綻
- TikTok Shopの手数料(5-8%)とアフィリエイト/広告費の二重コストで粗利が薄い
- 最も現実的なのはシナリオB(中単価×中量)で、月70-100個販売 = 月10万円利益

**推奨シナリオ: B（中単価3,000-5,000円帯)**
**現実的な達成期間: 8-12ヶ月**
**実質最小投資: 月3,000-5,000円(完全0円は虚構)**

## 1. 月10万円利益達成の数式分解（3シナリオ）

### 1.1 前提となるコスト構造（2026年6月時点想定）

| コスト項目 | 比率/金額 | 根拠 |
|-----------|----------|------|
| TikTok Shop手数料 | 売上の5.0%(プロモーション枠込で最大8%) | 2024-2025年公表料率の延長線 |
| Instagram Shop手数料 | 売上の5.0%(オンサイト決済) | Meta公表 |
| 決済手数料 | 売上の3.6% | Stripe/Shopify Payments標準 |
| ドロップシッピング原価 | 売上の40-55% | 中国系サプライヤー(CJ/Spocket)平均 |
| 配送費(送料込み価格前提) | 売上の8-15% | 国内配送/航空便ミックス |
| 返品・不良品ロス | 売上の5-8% | アパレル系平均値 |
| ツール代(Phase 1以降) | 月3,000-5,000円固定 | Canva Pro/サブスク等 |

**実効粗利率の試算**：
売上100に対し → 手数料5+決済3.6+原価45+配送10+返品6 = 69.6
**粗利率 = 30.4%** (これがベース想定)

## 2. オーガニック集客のファネル試算

### 2.1 ファネル全体図（シナリオB前提）

```
[投稿視聴数: 200,000回/月]
        ↓ CTR 3%
[プロフィール/商品ページ訪問: 6,000人]
        ↓ CVR 1.5%
[購入: 90個] = 月売上36万円 = 月利益10万円
```

### 2.2 必要月間投稿数の試算

| 指標 | 値 | 根拠 |
|------|-----|------|
| 1投稿の平均再生数(初期-中期) | 3,000-8,000回 | TikTokフォロワー0-1万のレンジ |
| バズ率(10万再生超) | 1-3% | 業界肌感 |
| バズ動画の平均再生数 | 30-80万回 | 中央値 |
| **必要投稿数** | **月25-40本** | 通常投稿×30本 + バズ1本前提 |

### 2.3 制作時間の試算(AI活用前提)

| 工程 | 時間/本 | AI活用後 |
|------|--------|---------|
| 商品リサーチ | 30分 | 10分(GPT/Perplexityで競合分析) |
| 構成・台本作成 | 20分 | 5分(Claude/ChatGPTで生成) |
| 撮影・編集 | 60分 | 30分(CapCutテンプレ+AI字幕) |
| 投稿・タグ最適化 | 10分 | 5分(AIサジェスト) |
| **合計** | **2時間/本** | **50分/本** |

### 2.4 稼働時間の検証

- 必要投稿数: 30本/月
- 1本あたり: 50分(AI活用後)
- **月間制作時間: 25時間 = 週6.25時間**
- 加えて、顧客対応・サプライヤー連絡・分析: 週2-3時間

**結論: 週8-10時間でギリギリ回せる。週5時間は厳しい**

## 6. ユニットエコノミクス推奨シナリオ

### 6.1 推奨: シナリオB(中単価×中量)

#### 推奨理由

1. **オーガニック集客で達成可能な販売数(月90個 = 3個/日)**
2. **粗利率30%確保しやすい中単価帯**(差別化余地が大きい)
3. **コンテンツ訴求しやすい**(悩み解決系・ガジェット系・美容系)
4. **返品率が低い**(低単価ほど雑に買って返品される傾向)
5. **個人ブランド構築に最適**(高単価ほど信頼資産が重要)

### 6.2 推奨ニッチ例

| ジャンル | 想定単価 | 粗利率 | バイラル相性 |
|---------|---------|--------|------------|
| 美容ガジェット(LED美容器・頭皮ケア等) | 3,000-5,000円 | 35-45% | ◎ |
| 時短キッチン用品 | 2,500-4,500円 | 30-40% | ○ |
| ペット用便利グッズ | 3,000-5,000円 | 30-40% | ◎ |
| 子育てお助けアイテム | 3,000-6,000円 | 30-35% | ○ |
| ガジェット系(スマホ周辺) | 3,000-5,000円 | 25-35% | ○ |

### 6.3 推奨シナリオのユニットエコノミクス

```
ARPA(平均注文単価)  : 4,000円
Gross Margin %     : 30%(実効)
リピート率(3ヶ月)   : 15-25%
LTV(初回購入のみ)   : 1,200円
LTV(リピート込)     : 1,500-1,800円
CAC(オーガニック中心): 200-500円(時間コスト換算)
CAC(広告込み)       : 800-1,500円

LTV / CAC          : 2.0-3.0倍   → ぎりぎり健全ライン
Payback Period     : 即時(初回購入で回収)
```

## 7. 率直な達成可能性評価

### 7.1 月10万円達成の現実評価

| 評価軸 | 内容 |
|--------|------|
| **達成可能性** | 6-12ヶ月で20-30%、12-24ヶ月で35-50% |
| **構造的優位性** | オーガニックSNS×ドロップシッピングは参入障壁が低い分、競合過多 |
| **個人差** | 動画クリエイティブのセンス・ニッチ選定眼で結果が3-5倍ぶれる |
| **時給観点** | 達成過程は最低賃金以下。達成後でも時給3,000円台 |
| **資産性** | フォロワー資産・ブランド資産が積み上がれば翌年以降は半自動収益化可能 |

### 7.2 「ギャンブル」か「現実的」か

**結論: 構造的にはギャンブル寄りの現実的事業**

理由:
1. **平均達成率20-30%**は、転職や資格取得より低い成功率
2. **アルゴリズム依存**でTikTok/Instagram側の判断1つで売上が消失するリスク
3. **時給換算で見ると割に合わない**期間が長く、本業を持つ副業者には継続困難
4. ただし、**月3-5万円レベルなら達成率は60-70%**まで上がる

### 7.3 副業者に対する率直な提言

- **月10万円は最終ゴールとし、Phase別の小目標(月1万→3万→5万→10万)で達成感を維持せよ**
- **本業を辞めて専業化するのは月利益が安定して20万円超えてから**
- **半年やってPhase 1の月1万円すら未達なら、ニッチ選定が根本的にズレている。撤退も合理的選択**
- **稼ぐより「コンテンツ制作力」が積み上がる副次的価値の方が大きい場合もある**
- **AIツール代3,000-5,000円は投資対効果が高い。「完全0円」にこだわるべきでない**

### 7.4 撤退判断のサマリー

| 期間 | 未達ライン | 推奨アクション |
|------|----------|--------------|
| 3ヶ月 | 月売上1万円未達 | ニッチ変更 |
| 6ヶ月 | 月利益3万円未達 | ジャンル/フォーマット根本変更 |
| 9ヶ月 | 月利益5万円未達 | ピボット検討(別の副業へ) |
| 12ヶ月 | 月利益5万円未達 | 撤退も合理的選択 |
