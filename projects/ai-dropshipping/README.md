## 調査で判明した最重要事実（2026年6月時点）

1. **AliExpress直送型ドロップシッピングは日本のTikTok Shopでは構造的に成立しない**
   - 3営業日以内発送ルール（違反3回でアカウント停止）に直送モデルは適合不可
2. **TikTok Shop日本は急成長中**（月次GMV 7月4億→12月60億円、セラー5万店超）だが、上位の66%は海外勢
3. **TikTok Shop出店（セラー側）には開業届が必須**。一方、**アフィリエイト（クリエイター側）はフォロワー1,000人で参加可能・登録のみ・在庫ゼロ**
4. 月10万円達成確率は20〜30%（6〜12ヶ月）。月3〜5万円なら60〜70%

## 採用戦略: 「2段ロケット」方式

```
Stage 1（月0〜3）: TikTok Shopアフィリエイト先行
  ├─ 完全0円・在庫ゼロ・開業届不要
  ├─ ニッチ特化アカウントを育成 → フォロワー1,000人でアフィリエイト解禁
  ├─ 報酬率5〜20%で初収益化
  └─ 目的: ニッチ×フォーマットの検証 ＋ 学習資産（制作力・フォロワー）の蓄積
     ↓ 検証済みニッチが見つかったら
Stage 2（月3〜6以降）: 国内仕入れ型ドロップシッピングへ拡張
  ├─ NETSEA / TopSeller等の国内サプライヤー（3日発送ルール適合）
  ├─ BASE/STORES開設 → 軌道に乗ったらTikTok Shop出店（開業届提出）
  └─ シナリオB: 単価4,000円 × 実効粗利30% × 月90個 = 月10万円利益
```

## 月10万円の数式（推奨シナリオB）

| 指標 | 値 |
|------|-----|
| 商品単価 | 3,000〜5,000円（中単価帯） |
| 実効粗利率 | 30%（手数料・原価・配送・返品込み） |
| 必要販売数 | 月90個（1日3個） |
| 必要視聴数 | 月20万再生（CTR3%×CVR1.5%） |
| 必要投稿数 | 月25〜40本（AI活用で1本50分） |
| 必要稼働 | 週8〜10時間 |
| 実質最小予算 | 月3,000〜5,000円（CapCut Pro/Canva Pro/サンプル品） |

## ニッチ候補（優先順）

| 順位 | カテゴリ | ターゲット | 単価/粗利 | 補足 |
|------|---------|-----------|----------|------|
| 1 | 家事・収納・キッチン雑貨（時短系） | 28〜40歳主婦層 | 2,000〜4,000円 / 30〜45% | 法規制リスク低・国内仕入れ充実・通年需要 |
| 2 | スマホ・ガジェットアクセサリ | 全年代 | 1,000〜2,500円 / 35〜50% | フィルム/スタンド限定（PSE系は絶対NG） |
| 3 | ペット用品 | 飼育者全般 | 1,500〜4,000円 / 35〜50% | シェア性最強・アフィリエイト相性◎ |
| 4 | 健康・ウェルネス小物（非効能訴求） | 30〜45歳 | 〜2,500円 / 40〜60% | 薬機法表現に要注意 |

## 法規制チェックリスト

- [ ] 副業所得20万円/年超 → 確定申告（Stage 1から該当しうる）
- [ ] Stage 2移行時: 開業届（TikTok Shop出店に必須）
- [ ] Stage 2移行時: 特定商取引法表記（バーチャルオフィス月1,000円〜で住所公開回避可）
- [ ] 薬機法: 効能効果の表現禁止（「治る」「痩せる」NG /「気持ちいい」OK）
- [ ] 景表法: 「最安」「No.1」等の優良誤認NG
- [ ] PSE法: バッテリー・充電器・電源系商品は扱わない（刑事罰リスク）
- [ ] TikTok規約: 3営業日発送 / 24h返信率80% / プラットフォーム外取引（LINE誘導等）禁止
